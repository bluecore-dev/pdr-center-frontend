# PDR Center — Next.js frontend (prototype)

**Early Next.js prototype of the PDR Center website**, generated with Google AI Studio: project configuration, authentication scaffolding, Prisma setup and admin helpers. The production site lives in **[pdrc-center-uzbekistan](https://github.com/bluecore-dev/pdrc-center-uzbekistan)**.

![Next.js 15](https://img.shields.io/badge/Next.js-15-000000?logo=nextdotjs&logoColor=white) ![React 19](https://img.shields.io/badge/React-19-61DAFB?logo=react&logoColor=black) ![Prisma 6](https://img.shields.io/badge/Prisma-6-2D3748?logo=prisma&logoColor=white) ![NextAuth](https://img.shields.io/badge/NextAuth-4-7C3AED) ![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3-06B6D4?logo=tailwindcss&logoColor=white)

## Contents

| File | Purpose |
|---|---|
| `middleware.ts` | route protection with NextAuth |
| `add-admin.ts` | creates an admin user (bcrypt) |
| `test-prisma.ts`, `verify_backend.ts` | database and backend checks |
| `next.config.ts`, `tailwind.config.js`, `postcss.config.js` | build and styling |
| `metadata.json` | AI Studio applet metadata |

Stack: Next.js 15, React 19, Prisma 6, NextAuth 4, Zustand, Swiper, Motion, Gemini API (`@google/genai`).

## Status

Prototype — the application pages were not committed here. Development continued in [pdrc-center-uzbekistan](https://github.com/bluecore-dev/pdrc-center-uzbekistan).
